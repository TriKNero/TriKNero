# Hi 👋 I'm Kris

Full Stack Engineer (React / Node.js) with 10+ years of experience building high-load, production-grade web applications.

I focus on performance, architecture, and building systems that scale without turning into a mess over time. Most of my work is around TypeScript, React, Next.js on the frontend and Node.js on the backend.

Recently I’ve been working in Web3 space — built a Telegram Mini App on TON where users could trade memecoins, worked with blockchain integrations, wallets, and on-chain data.

Before that, I built products used in production by real companies — including a Chrome Extension + Electron app (~30k MAU) used by companies like Coinbase and DoorDash.

I like taking ownership, designing systems end-to-end, and shipping things that actually matter.
